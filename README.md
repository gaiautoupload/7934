# 7934 鋒霈環境科技主力雷達

純 HTML、CSS、JavaScript 的手機優先靜態網站，可由 GitHub Pages 直接從 `main` 分支根目錄發布，不需要伺服器、資料庫或 GitHub Actions。

## 本地每日更新

唯一正式更新入口是 `../7934_strategy/update_website_scheduled.bat`。Windows 工作排程 `7934_Website_Weekday_Update` 於週一至週五 18:15 執行，在本機驗證興櫃每日檔、重算核心分點、推估成本與庫存，最後更新 `data/snapshot.json` 並推送至 GitHub。

核心 20 名依 7934 全部可得歷史的累積淨投入資金排序，不使用單日排行榜冒充核心；每日、近 5、近 10、近 20 日頁籤只顯示這組核心分點在相應期間的買賣張數與金額。

推估成本使用 EMdss004 的每筆「分點 × 成交價位」買進明細加權；原始檔未提供同日成交時間，同日買賣採比例留存估算，並提供可能成本區間與價位明細筆數。7934 行情採 TPEx 興櫃每日加權平均成交價。

分點只代表行為節點，不代表已確認的自然人、共同控制人或實質受益人。影響力排名是歷史關聯，不是因果或投資建議。
